# estoque-pam
<h3>Sobre a atividade</h3>
Este projeto foi desenvolvido como atividade da disciplina de Programação de Aplicativos Mobile.

O objetivo da atividade é criar um aplicativo Android chamado Ars-Nova focando em musica utilizando Kotlin, jetpack composer e firebase para .

<h3>Objetivo</h3>
Criar um aplicativo simples usando do firebase pra logar e cadastrar usuarios.

<h3>🛠️ Tecnologias utilizadas</h3>
Android Studio
Kotlin
Jetpack Compose
firebase
<h3>📱 Funcionalidades do aplicativo</h3>
O aplicativo possui crud para gerenciamento de estoque.

▶️ Como executar o projeto
Abrir o projeto no Android Studio
Sincronizar o projeto com o Gradle
Executar o aplicativo em um emulador ou dispositivo físico
🖥️ Interface do aplicativo
A interface foi desenvolvida utilizando Jetpack Compose.

Cada botão possui uma cor diferente para facilitar a identificação da ação executada.
